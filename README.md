# Rendezvous 💌

Интерактивное приглашение на свидание — премиальный mobile-first SPA в одном файле `index.html`.

## Что внутри

- Персональное приглашение с плашкой даты и времени
- Романтический мини-квиз из 4 вопросов (один — с проверкой правильного ответа и мини-конфетти)
- Таймлайн вечера (16:30 → 17:00 → 19:30) и умный дресс-код Smart Casual
- Главный вопрос с убегающей кнопкой «Нет»
- Взрыв конфетти и отправка ответа в Telegram Bot API

## Настройка

1. В начале `<script>` в `index.html` заполни константы:
   - `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather
   - `TELEGRAM_CHAT_ID` — твой chat_id
   - `EVENT_DATE` / `READY_TIME` — дата и время готовности
2. Проверка локально: `python3 -m http.server 8000` → http://localhost:8000

> ⚠️ Репозиторий публичный: токен бота, вставленный в `index.html`, сможет прочитать
> любой посетитель страницы (это особенность клиентской отправки без бэкенда).
> Для разового романтического использования это ок, но не используй этот токен
> для ботов, к которым нужен ограниченный доступ.

## Деплой

Автоматический на GitHub Pages при каждом пуше в `main`
(см. `.github/workflows/deploy.yml`). После первого деплоя сайт доступен на
`https://arasvet.github.io/rendezvous/`.
