# Rendezvous 💌

Интерактивное приглашение на свидание — editorial minimal SPA в одном файле `index.html`.

## Экраны

1. **Обложка** — «Олеся Сахипова.»
2. **Анкета** — 4 вопроса: списки и bento-плитки, неверный ответ перечёркивает вопрос
3. **Программа** — таймлайн вечера + dress code
4. **«Ты со мной?»** — кнопка «Нет» растворяется под пальцем
5. **Финал** — конфетти + моноширинный лог в Telegram

## Конфиг Telegram (ключей в коде нет)

Токен и chat_id передаются через hash в URL и сохраняются в localStorage:

```
https://arasvet.github.io/rendezvous/#token=…&chat=…
```

После первого открытия hash исчезает из адресной строки сам.

## Тестирование из терминала

```bash
# полный смоук-тест: страница + структура + контрольная отправка в Telegram
RDV_TOKEN=<токен> RDV_CHAT=<chat_id> node test/flow-test.mjs

# тест локальной версии (python3 -m http.server 8000)
RDV_URL=http://localhost:8000 node test/flow-test.mjs

# собрать разовую ссылку для Олеси
RDV_TOKEN=<токен> RDV_CHAT=<chat_id> node test/flow-test.mjs --link
```

## Деплой

GitHub Pages, автоматически при каждом пуше в `main`.

## ⚠️ Разовость ссылки

После того как Олеся ответит (сообщение придёт в Telegram) — отзови токен
в @BotFather командой `/revoke`: старые ссылки перестанут работать,
бот продолжит жить с новым токеном.
